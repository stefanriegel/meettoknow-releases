# Roadmap

Direction, not a promise. Ideas: [new issue](https://github.com/stefanriegel/meettoknow-releases/issues/new/choose).

## Next

- Newer speaker model — faster, better speaker counts

## Later

- Teams speaker names
- Browser calls without a calendar event; auto-stop for browser calls
- CRM follow-up: log a meeting as a customer activity, with preview and confirmation
- More AI providers (API keys)

## Recently shipped

- Transcription on the Neural Engine
- On-device chat with citations; citations point at the quoted sentence
- Browser calls suggested from the calendar; link a meeting to a calendar event
- `claude` / `gemini` command line as AI provider
- Acknowledgements (About MeetToKnow)
- Gemma 4 on-device, sized to the Mac
- Record this call? and auto-stop with cut at the hang-up
- Screenshots off by default, text only
